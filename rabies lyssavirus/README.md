The first file is the 'Creating rabies lyssavirus dataset from NCBI Virus data.ipynb' file. The file contains the code for creating the rabies lyssavirus dataset. Using the codes of this file, the dataset was generated from the curated rabies lyssavirus data from NCBI Virus Data.

After creating the dataset, preprocessing of the data was done to resize the sequences to 400 bases and to replace the unknown characters with 'N'. The codes are in 'rabies lyssavirus Dataset Preprocessing.ipynb' file.

Finally, 'BiLSTM_VHP Rabies Lyssavirus model training and testing.ipynb' file contains the code of creating 5 fold and creating, training and testing the model.
